# Queen Ashley Infrastructure — Projects

This repository contains web development projects and labs for the 2025 RTT course.

Open the folders below to view each project and its README:

- URL Shortener (Mod 7): [mod-7/url-shortener](mod-7/url-shortener)

Quick start (URL Shortener):

```bash
cd mod-7/url-shortener
# serve locally (requires Node)
npx serve .
# or with Python 3
python -m http.server 8000
```
